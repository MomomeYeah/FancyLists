# FancyLists frontend

React + TypeScript app built with [Vite](https://vite.dev/).

## Scripts

Run from this directory:

- `npm run dev` (or `npm start`) - start the dev server on [http://localhost:3000](http://localhost:3000).
  The port is fixed because the backend's CORS settings expect it.
- `npm run build` - type check and build for production into `build/`
- `npm run preview` - serve the production build locally
- `npm test` - run tests with [Vitest](https://vitest.dev/) in watch mode
